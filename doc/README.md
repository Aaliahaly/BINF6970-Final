# Documentation

This directory contains the main written documentation for the TCGA Lower Grade Glioma multi-omics database project.

---

## Main File

| File | Description |
|---|---|
| `Final Project Writeup.pdf` | Complete final project report covering the project overview, data source selection, database design, Python pipeline, SQL database construction, SQL queries, Neo4j analysis, biological interpretation, reproduction steps, limitations, and future work. |

---

## What This Document Covers

The final project writeup includes:

- Project overview and rationale
- Data source screening and inclusion/exclusion decisions
- Entity-relationship diagram
- Database design decisions
- Normalization up to Fifth Normal Form
- Data dictionary
- Python script map and cleaning decisions
- SQL database construction and population
- SQL queries with rationale and outputs
- Neo4j graph-based analysis
- Key mutated gene annotation
- Reproduction instructions
- Limitations and future work

---

## Related Directories

| Directory | Purpose |
|---|---|
| `data/` | Documents Figshare links for input, intermediate, final, SQL, and Neo4j files. |
| `scripts/` | Contains Python scripts for cleaning, harmonization, SQL generation, and Neo4j Cypher generation. |
| `sql/` | Documents SQL schema, SQL loading file, and SQL dump file. |
| `diagrams/` | Contains database diagrams and ERD files. |
| `docs/` | Contains the final project writeup. |

## Note

Large datasets and SQL files are not stored in this directory.

They are hosted externally on Figshare and linked in the main project README and `data/README.md`.
